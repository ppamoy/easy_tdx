# V732 审计总报告：easy_tdx 缠论模型 —— 准确性 / 标记正确性 / 能否指导选股择时

> 本文所有数字均来自本机实跑。凡"未验证"的事项已显式列出。
> 数据：新浪 `CN_MarketData.getKLineData` 前复权日线，30 只 A 股 + 沪深300/上证指数，
> 1500 根/只，区间 **2020-07-28 → 2026-09-30**，落盘于 `audit_data/`。

## 结论摘要（先给答案，再给证据）

| 问题 | 结论 | 证据强度 |
|---|---|---|
| 1. 实现有没有写错（结构不变式）？ | **基本正确**。I1–I7、I9–I12 全部 0 违反；**I8 有一处真实缺陷**（见下） | 强：32 只真实数据全量 |
| 2. 标记准不准（未来函数）？ | **修复前不准：40 组历史信号会被"补数据"改写（18/32 只标的受影响）。已修复 → 0 违反** | 强：224 组检查点 + 牙齿测试 |
| 3. 能否指导**择时**？ | **不能独立于"局部极值"提供价值**。信号 20 根均收益 +3.88%，但同样抽局部极值买入是 +4.30%，**信号反而低 0.42%（p=0.78）** | 强：双基准 + 独立第二口径复核 |
| 4. 能否指导**选股**？ | **不能**。信号数量与未来 60 根收益的 Spearman ρ 仅 -0.14~+0.04，全部不显著（p>0.31） | 中：横截面仅 30 只，样本薄 |

**一句话**：代码实现质量尚可，但缠论买卖点在本样本上的"预测力"**几乎全部来自
"买点必然靠近局部低点"这一定义上的同义反复**，而非结构本身的信息量。
它可以作为**结构化描述工具 / 择时过滤器**，**不能**单独作为选股或择时的决策依据。

## 一、结构不变式审计（`scripts/audit_chanlun_invariants.py`）

32 只标的全量扫描，I1–I12 + I8b：

| 不变式 | 内容 | 违反数 |
|---|---|---|
| I1–I7 | 顶底交替、笔端点共享、方向合法、ZD≤ZG、DD≤GG 等 | **0** |
| I9–I12 | 线段多义性、确定性、分型合法性等 | **0** |
| I8b | 构成笔必须与中枢区间 `[ZD,ZG]` 有重叠 | **0** |
| **I8** | **ZG/ZD 必须由≥3 个连续次级别走势重叠决定** | **缺陷（见下）** |

### I8 缺陷（真实问题，尚未修复）

- 591 个含 ≥3 笔的中枢中，**303 个（51.3%）** 的 ZG/ZD 实际只由**前 2 笔**冻结，
  第 3 笔及以后的笔**没有参与** ZG/ZD 的更新。
- ~~影响幅度：中枢宽度中位数 **2.56 → 3.32（+30%）**，最大 **+215%**。~~
  **⚠️ 已证伪（V733）**：该方向写反了。重测 557 个中枢，改为 3 笔口径后
  52.2% **变窄**（中位 −4.0%，均值 −19.0%），47.8% 不变，**0% 变宽**。
  数学上必然如此——多求一次交集只可能更窄。详见 V733 报告。
- 但：按严格的 3 笔规则重算，**0 个**中枢变为非法 —— 说明当前实现偏保守（中枢偏窄），
  不会造成"中枢失效"，但会让 3买/3卖 的 ZG/ZD 判定阈值系统性偏紧。
- **未修复原因**：这是行为变更，会改变所有历史信号，需单独评估 + 用户决策。已记录在案。

### 我自己踩的坑（记录在案，避免后人重复）

第一版 I8 断言写成"ZG ≤ 每个构成笔的 high"，产生 **1861 个假违反**。
实测纠正：缠论只要求构成笔与 `[ZD,ZG]` **有重叠**，GG/DD **允许**超出 ZG/ZD。
改写后 I8/I8b 分别归位。**如果不做这一步，I8 的结论会是假的。**

## 二、未来函数审计（`scripts/audit_future_leak_real.py`）—— 本轮最重要的发现

### 根因（已定位到具体代码）

`mmd_conditions.py::_calc_atr_volatility(closes)` 取 `closes[-lookback:]`，即**序列尾部**。
`analyser.py:722` 用它把**整段历史**算出一个全局 `volatility` 标量，
`find_mmds_v44` 再把这个标量套用到**所有历史信号**上。

后果：**"后面又录入一批数据"会改写早期信号。**

### 实测证据

- 32 只 × 7 个截断检查点 = **224 组**，修复前 **40 组违反**，**18/32 只**标的受影响。
- 典型案例 `sh600009`：截断 600 根时 bar199 无 1buy；补齐到 1500 根后**凭空多出
  `1buy@199`**。原因是尾部 ATR 波动率从 0.0136 变到 0.0070（相对差 93.5%），
  跨越了 0.01 的"低波动 → 收紧阈值"档位边界。
- 定位手法：monkeypatch 该函数为常数后，40 组违反**全部消失** → 证明这是**唯一**泄漏源。

### 修复

1. 新增 `_calc_atr_volatility_asof(closes, end_index, lookback=20)`（PIT 正确，
   窗口锚在 `[end-lookback+1, end]`）。
2. `mmd.py` 中 1买/1卖 改用 `_threshold_asof(bi)`；3买/3卖 改用 `_vol_adjusted_params(bi)`，
   逐笔按自身端点定档，不再复用全局标量。

### 修复后

**224 组检查点、6172 个可比信号，0 违反，0 样本不足。**

### 回归测试（`tests/unit/test_chanlun_v732_volatility_asof.py`，5 项）

含**牙齿验证**：把 as-of 换回尾部口径后，未来免疫断言**必须失败**。
第一版牙齿测试用合成形态，实测**任何口径下都免疫**（4 振幅档 × 2 长度全部通过）
→ 合成形态无法暴露该泄漏，改用真实数据中实测能分化的 `sh600009` 前 600 根
（已固化为 `tests/fixtures/v732_vol_leak_{base,future}.json`）。
退化后确实多出 `1buy@199`，断言生效。

## 三、预测力审计（`scripts/audit_predictive_power.py`）—— 回答"有没有用"

1193 个信号（30 只，排除指数）。

### Q1 择时力：三重基准

| 基准 | 20 根"押对方向"收益 | 信号 vs 基准 |
|---|---|---|
| **信号本身** | **+3.88%**（胜率 70.9%） | — |
| 随机入场 | +0.07%（胜率 53.2%） | 信号显著胜出（p<0.001）✅ |
| **局部极值入场**（买→局部低点） | **+4.30%**（胜率 99.9%） | **信号低 0.42%，p=0.78 ❌** |

**这是本次审计最关键的一条**：买点在**定义上**就靠近局部低点（笔端点 = 分型极值），
所以"买点后会涨"极大程度上是**同义反复**。一旦用"同样是局部低点"作为对照组，
缠论信号的超额**完全消失**（24 个类型×窗口组合中，**0/24** 显著胜出）。

独立第二口径复核（`/tmp/rank_check.py`，1247 个信号，中位数/胜率口径）得到同样结论：
信号 +3.88% vs 极值 +4.30%，差 -0.42%，p=0.78。

> ⚠️ 注意：极值基准胜率 99.9% 是**设计使然**——它只挑真正的局部极值点，
> 且回看窗口 ±5 本身就已知未来 5 根（这是对照组的**前瞻性**，故意留着，
> 因为它让对照组**更强**；缠论信号在**更强**的对照组面前依然没能胜出，
> 结论方向不受影响）。

### Q2 选股力：横截面

30 只股票，用"全段信号统计"预测"最后 60 根收益"：

| 特征 | 绝对收益 ρ | 超额收益 ρ |
|---|---|---|
| 买点数 | -0.144 (p=0.44) | -0.144 (p=0.44) |
| 卖点数 | -0.188 (p=0.31) | -0.188 (p=0.31) |
| 净买点 | +0.037 (p=0.85) | +0.037 (p=0.85) |

**全部不显著，且方向不一致** → 不能用缠论信号数量做选股排序。

### Q3 稳健性

1买/1卖/3买/3卖 的 20 根收益在前后半段**均同号**（+2.67% ~ +5.55%），
说明"正收益"不是单一时段偶然。2买/2卖 样本不足（40/46），**不参与结论**。

## 四、我在本次审计中犯的错误（自证伪，均已修正）

2. **I8 不变式写错**（1861 假违反），已按缠论原文纠正，见第一节。

3. **牙齿测试用错形态**：合成形态无法暴露泄漏（见第二节）。

4. **一个测试被我的修复改变**：`test_normalize_recovers_slow_decline` 中 n=48

## 七、明确"没做 / 未验证"的事项

- **未做浏览器 e2e / UI 验证**：本轮全部为模型与数据层审计，未涉及 Web UI。
- **未修复 I8 中枢缺陷**（2 笔 vs 3 笔冻结 ZG/ZD）：属行为变更，需单独决策。
- **横截面仅 30 只**：Q2 选股力的样本量偏薄，ρ 不显著不能排除"功效不足"，
  只能说"本样本上未观察到选股力"。
- **仅日线级别**：未测试周线/月线/分钟线，也未测试级别联立（区间套）的预测力。
- **未做交易成本/滑点建模**：Q1 的收益是毛收益，未扣手续费与冲击成本。
- **极值对照组含 ±5 前瞻**（设计使然，见 Q1 注释）：它使对照组更强，不影响结论方向。
- **衰减/样本外**：Q3 只做了前后半段对比，未做严格样本外滚动验证。

## 八、给使用者的建议

1. **不要用缠论买卖点单独选股** —— 本样本上无横截面区分力（ρ ≈ 0，全部不显著）。
2. **可以用作择时"过滤器"，但不要当作"信号源"** —— 它标注的位置确实是局部极值，
   有结构化价值；但相对"随便找个局部低点买入"没有可测的增量。
   若要使用，应与**其他独立信息源**（基本面、资金流、市场宽度）结合。
3. **必须开启未来免疫检查**：本项目已修复一处全局 ATR 波动率泄漏，
   若后续再引入任何"用全序列统计量"的阈值，会重新引入同类问题。
   建议把 `scripts/audit_future_leak_real.py` 纳入 CI。
