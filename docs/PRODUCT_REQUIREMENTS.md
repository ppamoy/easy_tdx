# EasyTDX 产品需求梳理

> 版本：v1.0 · 2026-08-29
> 定位：把「缠论分析 + 回测」从工具升级为「**可学习、可验证、可培养盘感**」的 A 股研究网站，并把长赢理论从概念卡片落地为「**基本面数据驱动的历史时点选股**」。

---

## 1. 产品愿景

一个面向 A 股研究者的网站，两大支柱：

1. **缠论学习与回测**：基于精准的缠论买卖点模型，用户可以在历史数据上回测，并通过「逐步揭示训练 + 逐笔复盘讲解」学会缠论买卖点、培养盘感、亲手验证本模型的准确性。
2. **长赢基本面选股**：基于长赢理论（四季周期 + 树粮菜三维），用历史财务数据筛选好标的，并且**支持任意历史时点回看**——站在当年，用当年的数据，找出当时的好标的，再验证其后来的表现。

一句话：**「用历史验证理论，用训练培养盘感」**。

### 2.2 现状与目标的差距（关键缺口）

| 目标能力 | 现状 | 差距 |
| --- | --- | --- |
| 缠论「逐步揭示」盘感训练 | ❌ 无 | 完全缺失，需从 0 建设前端交互 + 后端「按 K 线步进」接口 |
| 缠论「逐笔复盘讲解」 | ❌ 无 | 回测有结果但无教学式讲解（为什么这里是 1买/1卖、结构依据） |
| 长赢「基本面选股」 | ⚠️ 概念卡片 | 现有 Changying 页面只有四季/树粮菜概念与单标的季节判断，**没有真正的数据驱动选股** |
| 长赢「历史时点选股」 | ⚠️ 雏形 | screening.py 有「选历史日期→扫描→分类→缠论回测」雏形，但分类基于**缠论结构数量**（bi/zs count），**不是基本面**；且单次最多扫 30 只 |
| gpcw 财报数据解析 | ⚠️ 待打通 | file-list 可读，但 **zip 下载返回 0 字节**（服务器侧文件不可得或需换数据源），records 为空——历史时点基本面选股的**关键数据依赖** |
| 基本面数据字段 | ⚠️ 无指标层 | 缺财务指标计算层（ROE/毛利率/净利率/现金流/负债/增速/分红等 → 树粮菜量化规则） |

### 2.3 已确认的产品决策（用户确认）

- 长盈理论 = 现有「长赢」体系（吴伟志《长赢》：四季周期 + 树粮菜三维）
- 盘感训练形态：**逐步揭示模式 + 回测复盘模式，两者都要**
- 基本面数据：**先打通 gpcw 历史财报，在线数据（新浪/东财）作补充**
- 选股范围：**自选池优先，逐步扩展**（先跑通流程再放开全市场）
- 优先级：**先做缠论学习回测**

## 3. 模块一：缠论学习回测（P0，先落地）

### 3.1 核心用户故事

> 我是缠论初学者/想验证模型的人。我选择一个标的和周期，网站把历史 K 线逐步展开。每当 K 线推进到可能形成买卖点的位置时，暂停并问我：「这里你判断是买点、卖点、还是不动？」 我提交判断后，网站揭示缠论引擎在该位置的真实结论，并用笔/中枢/背驰结构讲清楚「为什么」。一轮走完，给我评分和复盘，帮我形成盘感，同时验证模型准确率。

### 3.2 功能需求

#### F1 逐步揭示训练（盘感训练）
- 输入：标的 + 周期（日线/60分钟等）+ K 线根数 + 难度
- K 线从起点逐步向前推进（按根 / 按笔 / 自动节奏三种推进方式）
- 推进到「潜在关键点」时暂停：候选点 = 分型位置、中枢边界、潜在 1/2/3 类买卖点窗口
- 用户三个动作：**买 / 卖 / 观望**；可选填写「依据」（画一笔/标中枢）
- 揭示答案：缠论引擎在该点的真实信号（1买/2买/3买/1卖/…），给出：
  - 结构依据（所在笔方向、附近中枢 [zg,zd]、背驰强度、置信度、质量评级）
  - 事后验证（此后 N 根 K 线实际涨跌 → 这一步判断对了没有）
- 计分：方向对 + 类型精确 + 时机接近度，权重可配；累计得分、命中率、最佳/最差练习

#### F2 回测复盘讲解（教学复盘）
- 完整回测后，逐笔列出每一条买卖点信号，每一条可点击展开「讲解卡」：
  - 信号类型、日期、价格、置信度、质量评级(S/A/B/C/D)
  - **为什么成立**：笔方向、参考中枢、背驰/力度证据（可跳转图表定位）
  - **当时后续走势**：N 日后实际最高/最低/涨跌幅（成败验证）
  - 建议仓位/止损止盈（来自 changying_chanlun 策略参数）
- 复盘汇总：按类型统计命中率、平均收益、最佳标的——即「本模型在历史上的准确率报告」，正是用户要的**验证准确性**

#### F3 训练数据
- 支持任意历史区间回放（不是只能从「现在」往后退）
- 训练会话可保存/续练（localStorage + 可选后端持久化）

#### F4 与现有能力复用
- 缠论引擎 / ChanlunAnalyser（多周期）
- 回测引擎 performance（计算信号后 N 日收益）
- ChanlunChart.vue（在图表上高亮「当前位置」）
- 新后端 API：POST /api/v1/chanlun/train/session（返回完整缠论结构 + 候选点清单 + 事后验证序列），前端负责逐步揭示与判断比对

### 3.3 数据/接口需求（P0）
- 后端新增缠论「训练会话」接口：一次性返回 bars + bis + xds + zss + mmds + fractals + 每个 mmd 的「信号后 N 日收益」；前端本地做逐步揭示（无需流式）
- 图表组件新增「游标模式」：只渲染到第 K 根，之后区域灰化/隐藏

## 4. 模块二：长赢基本面选股（P1）

### 4.1 核心用户故事

> 我想知道「2019 年初、2021 年中、2024 年初」这些历史时点，按长赢理论（四季 + 树粮菜）分别该买哪些好标的。网站让我选一个历史日期，用**截至当天已披露**的财务数据，对自选池（后续全市场）打分分类，输出当时的树/粮/菜好标的清单，并显示这些标的自选股日期起到今天的实际走势，验证长赢理论是否真的能选出好标的。

### 4.2 功能需求

#### F5 基本面数据打通（gpcw 财报 + 在线补充）
- **修复 gpcw 财报下载**：当前 file-list 可读但 zip 下载 0 字节。需排查：get_calc_hosts 服务器是否提供 tdxfin 文件 / 是否需要下载 .dat 而非 .zip / 换可用的财报数据源
- 备选数据源：新浪财务接口（现成 sina.py 基建）按报告期拉取历史财务指标
- 统一为「**财务指标层**」：每股收益 EPS、ROE、毛利率、净利率、营收增速、净利增速、经营现金流、资产负债率、股息率/分红、市值、PE/PB 估值（按报告期组织，含**披露日**以便 point-in-time 截断）

#### F6 树粮菜量化分类（长赢三维）
基于财务指标的量化规则（初版建议，落地时再校准）：
- **🌳 树**：龙头地位（营收/市值分位）+ 高 ROE(≥15%) + 长期稳定成长（3年营收/净利正增长）+ 护城河（高毛利 + 低波动）
- **🌾 粮**：稳定盈利 + 高分红/股息率 + 低负债 + 估值合理（PE 处于历史中低位）
- **🥬 菜**：高景气赛道（营收/净利增速 >20%）+ 弹性（市值中小）+ 高波动
- 每只股票给三项分值，取最高档分类，并附打分明细（可解释）

#### F7 四季周期判断（历史时点）
- 在选定的历史日期 T，用截至 T 的市场数据（大盘指数走势、估值分位、涨跌家数、成交额）判断当时处于四季中的哪一季，输出该季的仓位与操作建议（复用 ChangyingView 的四季卡片数据模型，改为「历史时点」）

#### F8 历史时点选股（point-in-time，核心）
- 输入：历史日期 T + 市场/自选池 + 股票类型过滤（tree/grain/vegetable/all）
- 数据语义（**杜绝未来函数**）：
  - 只使用**披露日 ≤ T** 的财报（报告期晚于 T 或披露日晚于 T 的数据一律不用）
  - 行情只用到 T（甚至用 T 日收盘）
- 输出：当时的好标的清单（树粮菜分类 + 评分 + 入选理由）+ 当时季节/仓位建议
- 每条标的附带「自 T 日起的后续表现」：后 N 日/后 1 年涨跌幅、最大回撤 → 验证长赢理论有效性
- 复用现有 screening 路由雏形，但**把分类/评分从缠论结构替换为基本面指标**

#### F9 选股回测验证（长赢理论准确率）
- 批量模式：选多个历史时点（如 2015 熊市底、2018 贸易战、2020 疫情后、2024 初），输出每个时点的选股名单 + 后续表现汇总表
- 与同期的**随机/指数基准**对比，给出「长赢理论是否跑赢」的结论

### 4.3 数据/接口需求（P1）
- 财务指标层模块 easy_tdx/fundamental/（数据源适配：gpcw / sina；指标计算；披露日管理）
- 选股引擎 easy_tdx/fundamental/screener.py（树粮菜打分 + point-in-time 截断）
- 新 API：
  - GET /api/v1/fundamental/indicator/{market}/{code}?report_period=...
  - POST /api/v1/fundamental/screen（date + pool + stock_type → 名单 + 后续表现）
  - POST /api/v1/fundamental/season（date → 四季判断）
- 前端：ScreeningView 重构为「历史时点基本面选股」页面

## 5. 技术架构与数据要点

```
前端 (Vue3 + ECharts)
├ 缠论学习：逐步揭示训练 + 逐笔复盘讲解
├ 缠论分析：现有 ChanlunView
├ 长赢选股：历史时点基本面选股 + 四季 + 树粮菜名单
└ 回测：现有 BacktestView
        │ REST /api/v1
后端 (FastAPI)
├ /chanlun/analyze · /chanlun/train/session (新)
├ /backtest/*（引擎 · 绩效 · 评级）
├ /fundamental/indicator · /screen · /season (新)
└ /financial/*（gpcw 财报 · xdxr）
        │
数据层
├ TDX 行情客户端（K线/实时/板块）
├ gpcw 历史财报（待修复下载）· 新浪财务（备选）
├ 财务指标层（报告期 + 披露日 → point-in-time 截断）
└ 策略库 SQLite · 训练成绩（localStorage/可选持久化）
```

关键约束：
- **Point-in-time 纪律**：任何历史时点分析只允许使用「当时已可得」的数据，禁止用未来数据回填（这是「历史时点好标的」可信度的生命线）
- **多周期缠论**：训练支持日线/周线/分钟线，结构口径与 ChanlunView 一致
- **性能**：历史时点选股需要批量财务数据，先自选池(≤100只)再全市场；财报解析建议本地缓存（SQLite/parquet）

## 7. 验收标准

### P0 缠论学习回测
1. 选任意标的+周期，可启动逐步揭示训练：K 线逐步展开，关键位置暂停，可提交买/卖/观望
2. 揭示答案与缠论引擎一致（同一 mmd 清单），并给出结构依据 + 事后 N 日验证
3. 一轮完成给出评分（命中率、方向准确率、得分）；复盘页逐笔展开讲解卡
4. 浏览器实测（Playwright 截图）验证：训练页图表游标、复盘卡、评分面板渲染正常，console 零错误

### P1 长赢基本面选股
1. 指定历史日期 T，用披露日≤T 的数据选出自选池树/粮/菜清单，打分有明细、可解释
2. 清单含自 T 日起后续表现；批量时点（≥3个历史日期）可汇总验证「长赢理论是否跑赢指数/随机基准」
3. 无未来函数（用未来数据会被测试拦截）
4. 浏览器实测验证页面交互与图表
