# 模型准确度验证指南（V95–V168）

> 本文档汇总 easy-tdx 自 V95 起新增的「通过历史回测验证模型/策略准确度」能力。
> 目标：让用户不只是看账户盈亏，而是能回答三件事——**信号准不准、稳健不稳健、过不过拟合**。

## 二、核心概念

- **命中（hit）**：买入后 N 根收益 > 0（择时进场正确）；卖出后 N 根下跌（回避下跌正确）。
- **随机入场基准**：以相同信号数量在全部可入场 bar 上随机采样（可复现 seed，数据不足时直接用全量），作为「抛硬币择时」的下限参照。
- **超额命中率** = 模型命中率 − 随机命中率。>0 说明信号比随机择时更准。
- **模型可信度（V101 权重）**：40% 择时准确度 + 35% 稳健性 + 25% 绩效对比，融合成 0-100 分。
- **样本外验证（V105）**：把区间按时间切训练段（默认 70%）+ 样本外持有段（30%），策略参数固定，在模型从未见过的数据上重跑——检验过拟合最硬的一关。

## 三、如何启用

### 3.1 回测页（最常用）

1. 选择标的与策略，点击「开始回测」。
2. 在「资金与成本」区勾选：
   - **分段稳健性检查**：把区间切成 2~6 段逐段重跑，看各段表现是否一致。
   - **样本外验证**：训练段 + 未见过持有段对比。
3. 报告区依次展示：✅ 验证总结（V106）→ 📊 模型可信度（V101）→ 🎯 模型准确度验证（V95）→ 🧱 分段稳健性（V97）→ 🔬 样本外验证（V105）。
4. 想留存/分享？点工具栏「📋 复制报告」导出 Markdown 摘要（V104）；「⚙ 复制 JSON」（V153）导出完整结构化的机器可读验证档案（performance/signal_accuracy/segment_robustness/model_trust/out_of_sample 等），供 Agent/脚本消费与存档。
5. 工具栏「🗳️ 批量验证自选股」（V137）：读取全局自选股（最多 12 只），用当前策略+参数逐只独立回测，按 V101 可信度降序排名；每行「查看该股」直接切换目标重新回测；面板头部「📋 复制排名」（V139）把结论导出为 Markdown 表格、「⚙ 复制 JSON」（V157）导出机器可读结果、「💾 保存为组合策略」（V141）把验证选出的股票一键入策略库（kind=portfolio，source=batch-verify-backtest），可在组合回测页载入复跑；「按收益 / 按可信度」切换（V149）在选股与收益对比间切换排序。

### 3.2 缠论分析页

- 分析完成后，「买卖点准确度验证」面板（V96）展示每类买卖点（1buy/2buy/3buy/各 sell）的 5 根命中率与随机基准对比。

### 3.3 动态选股页

- 扫描出符合条件的股票后，点「📈 验证选股效果」（V98）回看选股日后 5/10/20/60 日收益，对比选中组 vs 未选中池。

### 3.4 组合回测页

- 报告展示「组合准确度验证」（V99）与「组合可信度」横幅（V103）。
- 资金与成本区可勾选「样本外验证」（V126）与「训练占比」，报告区展示「🔬 组合样本外验证」面板（逐标训练/持有切分聚合）。
- 工具栏「📋 复制报告」（V127）导出组合绩效 + 可信度 + 准确度 + 样本外的 Markdown 摘要；「⚙ 复制 JSON」（V162）导出完整结构化的组合结果（total_performance/individual_results/accuracy_summary/portfolio_trust/out_of_sample 等），供 Agent/脚本消费。
- 保存为组合策略（V134）时快照包含 accuracy/trust/out_of_sample 三组验证结论，策略库「组合」tab 卡片可直接展示。
- 标的列表下方「🧪 批量验证候选股」（V160）：读全局自选股（最多 12 只），用当前策略逐只独立回测并按 V101 可信度排名，支持「按收益/按可信度」切换，可单只或一键「加入组合」——先验证候选股再挑进组合，选股与组合打通。

### 3.5 信号监控页

- 「快速加入的信号」每项有「🎯 准确度」按钮（V107），点击查看该股最近 300 根日线的历史信号命中率。
- 主监控列表每股也有「🎯」按钮（V121），同样可核对历史命中率。
- 股票列表下方「🧪 批量验证监控股」（V143）：选一个策略，对已选监控标的（最多 12 只）逐只独立回测（最近 500 根日线），按 V101 可信度降序排名；面板头部「📋 复制排名」导出 Markdown、「⚙ 复制 JSON」（V166）导出机器可读结果、「💾 保存为组合策略」（V145，source=batch-verify-monitor）一键入库复跑；「按收益 / 按可信度」切换（V151）与回测页 V149 体验一致。

### 3.6 策略库与对比页

- 保存策略时（V100）自动把准确度/稳健性结论写入快照；V122 起快照还包含模型可信度（V101）与样本外验证（V105）结论，策略库卡片直接展示。
- 页头「按验证可信度排序」（V147）：开启后按快照 trust.score 降序展示，优先看到经过历史回测验证、可信度最高的策略。
- 卡片头部「验证来源」徽章（V164）：批量验证入库的策略（V131/V141/V145 的 source=batch-verify*）会显示「🧪 选股/回测/监控批量验证」徽章，一眼看出策略从哪个验证流程入库。
- 结果对比页（V102）横向展示多个 task 的 📊 可信度 / 🎯 5根命中率 / 🎯 超额命中率；V125 起补「🔬 样本外验证」「🧱 稳健性」两行，跨任务比策略时也看是否过拟合。

### 3.7 参数寻优页

- 单策略寻优（V109）：网格点排名表含「5根命中」「可信度」列；结果顶部新增「✅ 验证总结」卡片（V124）聚合最优点可信度/命中率/Walk-Forward 判定。
- 启用「Walk-Forward 验证」（V123）：报告区展示「🔁 Walk-Forward 滚动验证报告」——逐窗口训练/测试表现与防过拟合判定。
- 结果顶部「📋 复制报告」（V135）导出 Markdown；「⚙ 复制 JSON」（V158）导出完整结构化的寻优结果（strategy/results/best/heatmap/walk_forward 等），供 Agent/脚本消费。
- 一键寻优所有策略（V111/V113）：全局排名表含准确度/可信度列，支持「按收益 / 按可信度」切换排序，按验证过的准确度挑策略。

### 3.8 动态选股页（批量验证）

- 扫描出股票后，「批量策略验证」（V114）对前 12 只筛选股用所选策略分别回测，按模型可信度降序排名；每行「查看该股」（V118）直达该股的单标缠论回测视图。
- 结果区「📋 复制排名」（V130）把按可信度排名的结论导出为 Markdown 表格、「⚙ 复制 JSON」（V168）导出机器可读结果；「💾 保存为组合策略」（V131）把验证选出的股票一键存入策略库（kind=portfolio，带 source=batch-verify 快照），可在「策略库 → 组合」tab 载入后在组合回测页复跑。
- 策略库页勾选多个单标的策略可做「组合回测」；勾选「样本外验证」（V128）后组合结果区展示多策略组合级样本外验证面板。

### 3.9 命令行（CLI）

- `easy-tdx verify SZ 000001 --strategy ma_cross --segments 3 --out-of-sample`（V117）：单标的完整验证报告 JSON，verdict 汇总全部结论。
- `easy-tdx verify-multi "SZ 000001,SH 600519" --strategy ma_cross`（V119）：多标的批量验证，按可信度降序排名选股，适合脚本/Agent；加 `--segments 3 --out-of-sample`（V132）可让每只标的额外输出 overfit_likely/oos_degraded/train_return/test_return。
- `easy-tdx run-all SZ 300308`（V115/V155）：run-all 排名表补「5根命中」「超额命中」「可信度」列（V115），并按需追加「稳健性」「样本外」列（V155）——每策略额外计算分段稳健性（V97）与样本外（V105）结论。

## 四、如何解读

- **命中率高于随机基准（超额 > 0）**：择时有正贡献，值得参考。
- **命中率与随机相当**：择时贡献有限，收益可能来自行情本身。
- **分段稳健性显示过拟合 / 样本外衰减**：历史成绩可能不可持续，需谨慎对待。
- **模型可信度 70+ 高 / 50~69 中 / <50 低**：综合信号准确度、稳健性、绩效对比的加权结论。
