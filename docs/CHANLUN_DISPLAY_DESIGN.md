## 1. 区间套（第61课）：背驰段层级链 + 状态机 + 区间收缩

### 1.1 原文语义（必须忠实呈现）

第61课逐字：「65开始的走势是**第一重背驰段**，69开始的是**第二重背驰段**，也就是65开始背驰段的背驰段，而71开始的是**第三重背驰段**……72点这个背驰点的精确定位，是由65开始背驰段的背驰段的背驰段的背驰段构成的，这就构成一个**区间套**的精确定位」；「一旦力度大于前者，那么就可以断定背驰段不成立」。

⇒ 区间套 = 一串**逐重嵌套**的背驰段，每重是上一重的「内部背驰段」，区间 `[I₁ ⊃ I₂ ⊃ I₃ ⊃ I₄]` 逐级收缩，收敛到转折点；每重有 3 态：**ASSUMED（假设背驰段）/ CONFIRMED（力度确实衰竭，确认）/ REJECTED（力度大于前者，背驰段不成立）**。

⚠️ **关键区分**（AGENTS.md 案例 B，已实测证伪）：
- 第61课原文区间套 = **同走势逐重嵌套背驰段**（都在同一图、同一级别序列，逐重 zoom-in）。
- `qujiantao.cross_period` = 大级别 mmd + 次级别(30min)同向确认 = **跨周期确认**（确认率 ~50%，是另一种近似，不是第61课原文）。
- `levels`（同序列递归）= **伪区间套**（确认率 ~3%，不得当真区间套呈现）。
- 收益实测：真跨周期全量 285 只 + Bonferroni 后**无一显著**（`CHANLUN_MULTI_LEVEL_FULL_THEORY.md`）。

### 1.2 展示方案：区间套面板（新组件 `QujiantaoPanel.vue`）

**位置**：主图右侧 / 买卖点明细上方，点击图中某个 1买/1卖 时弹出。

**布局**（ASCII 草图）：
```
┌─ 区间套定位（第61课）─────────────────────────────────┐
│ 标的 sh000001 日线 · 锚点 2026-09-23 1买              │
│ 口径：真跨周期(日线+30min) ⚠ 非第61课原文嵌套，是近似 │
│                                                        │
│ 第1重  65→  背驰段 [3120, 3300]   ASSUMED ●           │
│   └─ 第2重  69→  背驰段 [3180, 3260]  CONFIRMED ●    │
│       └─ 第3重  71→  背驰段 [3200, 3240]  CONFIRMED ●│
│           └─ 第4重  71内 背驰段 [3210, 3230] PENDING ●│
│                                                        │
│ 区间收缩：[██████████████] 3300                       │
│           [████████] 3260                             │
│           [████] 3240                                 │
│           [██] 3230  ← 当下定位区间                   │
│                                                        │
│ 状态机：ASSUMED→力度<前者→CONFIRMED；力度>前者→REJECTED│
│ 结论：4重嵌套收敛，转折点落在 [3210,3230]，卖         │
└────────────────────────────────────────────────────────┘
```

**要素**：
1. **层级链**（树形缩进）：每重一行 —— 起点笔、背驰段区间 `[low, high]`、3 态徽标。
2. **区间收缩条**：每重一条横条，长度=区间宽度，垂直对齐，肉眼可见「逐重收缩」。最底下是当下定位区间。
3. **状态机图例**：ASSUMED(黄)/CONFIRMED(绿)/REJECTED(红)/PENDING(灰)，附第61课原文「一旦力度大于前者，就可以断定背驰段不成立」。
4. **口径声明**：显式标「真跨周期近似 / 第61课原文嵌套 / 同序列递归伪」，并把 AGENTS.md 案例 B 的 3% vs 50% 实测写在 ⚠ tooltip 里——**不能让用户把伪区间套当真的**。

### 1.3 后端改动（最小）

当前 `qujiantao.compute_qujiantao_cross_period` 只返回 `{nested, score, msg, method}`（一个布尔 + 分数）。要支撑层级链需扩展为：
```python
qujiantao: [
  {
    "anchor_mmd_index": int,
    "method": "cross_period" | "recursive",
    "layers": [
      {"level": 1, "bi_start": ..., "interval": [low, high],
       "state": "ASSUMED|CONFIRMED|REJECTED|PENDING",
       "macd_area": float, "prev_macd_area": float},
      {"level": 2, ...}, ...
    ],
    "converged_interval": [low, high],  # 最里重区间
    "note": "真跨周期近似，非第61课原文嵌套"  # 口径声明
  }
]
```
- **真跨周期**：用 `high_result.mmds[i]` + `low_result` 在锚点时间窗内的次级别背驰段链（`low_result.bcs` 已有，逐个往前嵌套）。
- **同序列递归**：用 `result.levels`（笔/线段递归级别）的背驰段链，但**必须带 ⚠ 伪区间套声明**。
- 第61课原文嵌套（理想）：需走势类型级递归（架构缺口，见审计 §2.1），暂以「跨周期 + 递归」两种近似呈现，并明确标注差距。

### 1.4 验收（行为级，AGENTS.md §1）
- 点 1买 → 面板弹出 → 层级链 ≥1 重 → 区间收缩条逐重变短 → 状态徽标与 `low_result.bcs` 力度比较一致（不是 DOM 存在性，是「最里重区间 ⊂ 最外重区间」且「CONFIRMED 的 macd_area < prev」）。
- 同序列递归口径下 ⚠ 声明**可见**（截图 + 视觉确认）。

## 2. 多级别联立（第33/38/40课）：多图联立 + 走势分解

### 2.1 原文语义

- 第33课「走势的多义性」：同一段走势可从不同级别看，结论不同。
- 第38课「同级别分解」：把走势按**同级别走势类型**依次切开（不混级别）。
- 第40课「同级别分解的多重赋格」：不同起点的同级别分解叠加。
- 第17课：级别必须递归 `L_{n+1}=f(L_n)`，中枢=3 个次级别走势重叠。

⇒ 多级别联立 ≠ 「一个 confluence 分数」。它是**多个级别的走势同屏对照**，
让用户看到「日线背驰段在 30min 里长什么样、在 5min 里是否先反转」。

### 2.2 展示方案：多级别联立视图（升级 `ChanlunView` 多级别模式）

**现状问题**：勾「多级别联立」只出 confluence 卡片，**看不到低级别图**。

**方案**：多级别模式下，主图区改为**垂直堆叠的多张 `ChanlunChart`**：
```
┌─ 日线（高级别）──────────────────────────┐
│  K线 + 笔 + 线段 + 中枢 + 1买●(锚点)      │
│  ─────────────▲────────────── (锚点时间线贯通)
├─ 30min（次级别）─────────────────────────┤
│  K线 + 笔 + 线段 + 中枢 + 次级别背驰●     │
│              ▲ (同一时间点的次级别结构)
├─ 5min（次次级别，可选）───────────────────┤
│  K线 + 笔 + 中枢                          │
└──────────────────────────────────────────┘
左侧时间轴对齐：点日线某笔 → 三图同步竖线高亮该时间窗
```

**要素**：
1. **多图堆叠 + 时间对齐**：N 张 `ChanlunChart`（复用现有组件，传不同 level 的 bis/zss/mmds），共享一条「锚点时间竖线」——点高级别任一笔/买卖点，次级别图自动滚到同时间窗并高亮。
2. **confluence 卡片保留**但降为副信息：一致度%、trend/zs/time_aligned 仍显示，但主信息是「图」。
3. **同级别分解切换（第38课，标注「未实现」）**：一个下拉「走势分解：递归级别 / 同级别分解（第38课）」。选「同级别分解」时若后端未实现，显式提示「第38课同级别分解未实现（架构缺口，见审计 §2.4）」，**不假装有**。
4. **级别链徽标**：每个买卖点显示「日线1买 ← 30min 1买 ← 5min 盘整背驰」的级别链（第17课定律：大级别买卖点必为某次级别买卖点）。

### 2.3 后端改动
- `/chanlun/multi-level` 已返回 `high_level.result` + `low_level.result`（各含完整 bis/zss/mmds/bcs），**前端直接渲染两张图即可**，无需新端点。
- 可选加 `low_level_2`（5min）做三图：扩展 `ChanlunMultiLevelRequest` 加 `low_level_2`。
- 同级别分解（第38课）：架构缺口，前端只放占位 + 声明。

### 2.4 验收
- 勾「多级别联立」→ 出现 ≥2 张图 → 点日线笔 → 30min 图同步竖线 → 该时间窗内 30min 确有结构（笔/中枢/买卖点，不是空图）。
- 「同级别分解」下拉 → 选未实现项 → 看到「未实现」声明（截图确认）。

### 3.2 五个买卖点精准识别工具

每个工具 = 原文判据（逐字） + 模型字段（已有，无需新端点） + 交互（主图聚焦 + 依据浮窗 + 可信度）。用户**点工具 → 图上标出所有候选点 + 每点的原文依据 + 保真度**，当下判定。

#### 工具①：1买趋势背驰定位器（第21/27/29课）
- **原文判据**：①下跌确立（≥2 同向下跌中枢，第21课）；②C 段 MACD 面积 < A 段（第27课趋势背驰）；③后置验证：反弹触及中枢 DD/GG（第29课背驰-转折定理）。
- **模型字段**：`mmds[type=1buy]` + `mmd._downtrend_established`（V4 已验）+ `bcs[趋势背驰]` + `mmd.rebound_verified`。
- **交互（✅ MVP 已落地）**：1买/1卖明细标背驰确立状态徽章——`✓背驰确立`(b1-confirmed 绿)=rebound_verified=true（反弹触及中枢DD/GG，第29课转折定理符合）；`⚠疑似背驰`(b1-suspect 黄)=false（未触及，可能非真背驰）；`?待验证`(b1-pending 灰)=null（最新信号数据不足）。title 含第29课原文依据。实现：`web-ui/src/utils/mmdStatusBadge.ts` + ChanlunView 徽章模板 + `mapMmds` 透传 `rebound_verified`。
- **保真度**：✅（V4 行为级 26/26 1买已确立；rebound_verified 第29课后置验证在 API）。

#### 工具②：2买第一次回调定位器（第17/101课）
- **原文判据**：1买后**第一次次级别回调**的低点（第17课）；第101课三形态：①一般（依次向上）；②最强（2、3买合一）；③最弱（**2买跌破1买，完全可以**）。
- **模型字段**：`mmds[type=2buy]`（`mmd_2nd_max_pullback=None` 默认原文口径，第101课最弱可达）+ 配对 1buy + 回调笔 `mmd.bi`。
- **交互（✅ MVP 已落地）**：买卖点明细里每个 2买/2卖 标形态徽章——`⚠最弱·破1买`(m2-weakest 红)=2买跌破1买（第101课最弱，§2.3 修复前被 50% 门槛吞掉，现可达可见）；`一般`(m2-general 灰)=高于1买。无配对1买/非2买卖不渲染。实现：`web-ui/src/utils/mmd2Form.ts`（前端按 anchor_val 配对比较）+ ChanlunView 徽章模板 + CSS。实测 8 只日线：2买/2卖 55 个，最弱 21（38%，含跌破1买 14）、一般 34。
- **保真度**：✅ §2.3 已修（V3 11/26 低于1买）；§2.2 2买=次级别1买仍 ⚠️（架构级，待§2.1）。

#### 工具③：3买突破ZG回踩定位器（第20课）
- **原文判据**：突破中枢 ZG 后**第一次回踩不破 ZG**（第20课定理）。
- **模型字段**：`mmds[type=3buy]` + 配对中枢 `zs.zg` + 回踩笔 `mmd.bi`（`bi.low > zs.zg`）。
- **交互（✅ MVP 已落地）**：3买/3卖明细标 ZG安全距离徽章——`回踩{val} vs ZG{zg}`(b3-ok 绿)=不破ZG+正安全距离（第20课合法）；离ZG越近风险越高；破ZG 标 b3-bad 红（检测已过滤，徽章如实标）。3卖对称（vs ZD）。实现：`web-ui/src/utils/mmdStatusBadge.ts` + 后端 mmd to_dict 新增 `zs_zg`/`zs_zd`（additive，§2.4 round）+ `mapMmds` 透传。
- **保真度**：✅。

#### 工具④：区间套逐重收敛（第61课）
- **原文判据**：大级别背驰段（ASSUMED）→ 次级别背驰段（CONFIRMED 力度衰减 / REJECTED 力度未衰减）→ 逐重收缩定转折点。
- **模型字段**：`mmd.qujiantao.state`（ASSUMED/CONFIRMED/REJECTED）+ `mmd.qujiantao.chain`（逐重链，现状1重）+ `mmd.qujiantao.score`。
- **交互（✅ MVP 已落地）**：买卖点明细徽章按三态分色——`🔗 套`(qt-ok 绿)=CONFIRMED 本重背驰确认；`🔗✗`(qt-reject 红)=REJECTED 背驰段不成立（力度未衰减，别交易）；`🔗?`(qt-assumed 灰)=ASSUMED 待观察。递归口径标 `🔗 级?`(qt-recursive) 与真跨周期区分，title 前置来源警告。实现：`web-ui/src/utils/qtBadge.ts`（单一真源）+ ChanlunView 徽章模板 + CSS。
