# 缠论模型正确性实测（50 只市值 ≥100亿，日线 + 30分钟）

> 本文只回答一个问题：**缠论买卖点的方向判断到底对不对**。
> 它**不回答**"能不能赚钱" —— 那是另一回事（行情好时模型错也能赚钱）。
> 两者分开测，不混为一谈。

## 判据（三层，越往上越硬）

| 层 | 问题 | 怎么判 |
|---|---|---|
| L1 方向 | 买点后真涨？卖点后真跌？ | 方向化后均值 > 0（买看涨、卖看跌，统一"对了就为正"） |
| L2 胜过随机 | 比随机入场强吗？ | 与**同数量随机入场**（固定种子）对照，超额 > 0 |
| L3 显著 | 这个超额是运气吗？ | 配对 t 检验 + **Bonferroni 多重比较校正**（24 次比较 ⇒ \|t\| > 3.08） |

不校正的后果：测 24 次里必然有约 1 次"显著"是运气。

复现：
```bash
.venv/bin/python scripts/verify_chanlun_correctness.py --limit 50 --level daily
.venv/bin/python scripts/verify_chanlun_correctness.py --limit 50 --level 30min
```

## ⚠️ 必须同时说明的三点

### 1. 方向对 ≠ 扣完成本还赚

超额都在 **1~6%** 量级（30min 只有 1~2%），而交易成本约 **0.56%**（双边：
佣金 0.0003×2 + 印花税 0.001 + 滑点 0.002×2）。**方向对不等于能赚钱**。

### 2. 这是"平均效果"，不是"每个信号都对"

t 检验说的是**平均意义上**胜过随机。单个信号仍然经常错。用户不能照单全收。

### 3. 1买/2买 的结论要打折

按 `docs/CHANLUN_MULTI_LEVEL_FULL_THEORY.md` §7：**2买/1买尚未做修复前后对照回测**。
3买/3卖是原文级可信实现，这两类结论可以直接采信；1买/2买需谨慎。

## 已修的污染性 bug（都很隐蔽，别改回去）

### 1. 随机基准用了两个不同下标

```python
# ❌ 错：同一个表达式调用两次 r()
closes[int(r()*e)+h] / closes[int(r()*e)] - 1
# ✅ 对：同一个 j
j = int(r()*e); closes[j+h] / closes[j] - 1
```
后果：算出来的不是任何一次入场的收益，方差被人为放大 ⇒ 显著性失真。
**修复前 3buy 三档全被误判 ❌（t=−7.29），修好后变 ✅（t=13.56）。**

### 2. 方差为 0 时 t 返回 0

差值非零但方差为 0（每对都一样大）⇒ 数学上 t → ∞，但原实现返回 0.0，
会被读成"没有效应"。真实含义是"效应完美一致"。

两个坑都由 `tests/unit/test_chanlun_correctness_script.py`（9 例）锁住，
且**注入坏版本验证过测试会变红**。

## 🔴 已证伪：「类二买方向是反的」（2026-10-10）

**本文此前报告 `2buy_s`（类二买）方向是反的（日线 t=−7.23、30min t=−4.81），
该结论是错的，是我的 bug，不是模型的问题。**

### 根因

判定买卖方向时用了：
```python
is_buy = t.endswith("buy")     # ❌ 错
```
而 `2buy_s` 以 **`_s` 结尾** ⇒ `endswith("buy")` 返回 False ⇒ 被当成**卖点取反**。

权威口径（与 `chanlun/mmd.py` 一致）是子串判断：
```python
is_buy = "buy" in t            # ✅ 对
```

### 证据：只有符号反了，数值一模一样

| 信号 | 修复前（错误） | 修复后（正确） |
|---|---|---|
| 类二买 5根 | ❌ −4.76% (t=−7.10) | ✅ **+4.76%** (t=**+7.10**) |
| 类二买 10根 | ❌ −5.11% (t=−3.99) | ✅ **+5.11%** (t=**+3.99**) |
| 类二买 20根 | ❌ −4.61% (t=−5.80) | ✅ **+4.61%** (t=**+5.80**) |

绝对值完全一致、仅符号相反 —— 取反 bug 的确凿特征。

### 修正后的结论

**七个买卖点类型全部方向正确，无一例外。**

修正后重跑（50 只 × 两个级别）：

| 级别 | ✅ 显著 | ⚠️ 不显著 | ❌ 方向错 | 方向正确 |
|---|---|---|---|---|
| 日线 | 19 | 5 | **0** | **24/24** |
| 30min | 22 | 2 | **0** | **24/24** |

### 为什么会发生（值得记住）

这个坑**本项目踩了两次**：
1. 首次：`V733_AUDIT_REPORT.md` 五之九 —— 文档里明确写了
