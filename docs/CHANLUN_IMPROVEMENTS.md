# easy_tdx 缠论模型改进报告 v86-v87

## 改进概览

本次改进针对 easy_tdx 项目的缠论（Chanlun）核心算法进行了全面优化，旨在：
1. **按缠论理论定义画对笔、线段、中枢、买卖点**
2. **提高缠论模型买卖点精准判断**
3. **让用户能通过历史回测检查模型准确性**

---

## 一、核心算法改进

### 1. 笔(bi)计算改进 (v86) - `src/easy_tdx/chanlun/bi.py`

**新增功能：**
- `_check_bi_endpoint_consistency()`: 端点方向一致性校验
  - 向上笔：起点必须是底分型，终点必须是顶分型
  - 向下笔：起点必须是顶分型，终点必须是底分型
  
- `_is_weak_bi()`: 弱笔检测
  - 价格变动 < 0.1% 的笔标记为弱笔

**改进逻辑：**
- 修复了"分型陷阱"场景的边界情况
- 增加了更严格的方向交替验证
- pending保护逻辑优化，避免算法卡死

### 2. 中枢(zs)计算改进 (v87) - `src/easy_tdx/chanlun/zs.py`

**新增功能：**
- `_is_valid_zs_range()`: 中枢区间有效性检查
  - zg必须严格大于zd
  - 中枢宽度至少为价格的0.1%
  
- 动态重叠率阈值
  - 小价格区间使用更宽松的重叠率要求（最低2%）
  - 大价格区间保持5%默认阈值

- `_should_close_candidate()`: 稳定性检查辅助函数

**改进效果：**
- 减少虚假中枢（狭窄区间、退化单点）
- 提高中枢识别的稳定性

### 3. 线段(xd)计算改进 (v87) - `src/easy_tdx/chanlun/xd.py`

**严格化检查：**
- 特征序列分型判定增加严格性
  - 中间特征笔必须是局部最高/最低点
  
- 线段方向一致性验证
  - 向上线段终点必须高于起点
  - 向下线段终点必须低于起点

- 最小线段长度检查（至少3笔）

### 4. 背驰(bc)计算 - `src/easy_tdx/chanlun/beichi.py`

**三种背驰类型：**
- 笔背驰：相邻同向笔力度比较（比率<80%）
- 盘整背驰：中枢内末笔vs首笔
- 趋势背驰：连续同向中枢离开力度比较

**改进：**
- 只在同向笔之间比较（避免跨方向误判）
- 趋势背驰需确认中枢同向排列

### 5. 买卖点(mmd)识别 - `src/easy_tdx/chanlun/mmd.py`

**一类买卖点（V1买/V1卖）：**
- 增加趋势强度检查（≥2个同向中枢）
- 双重去重：相邻1买至少相隔5笔 + ≥3%反弹
- 成交量异常检测（底背驰放量=机构接盘）
- 缺口分析（向下缺口=加速赶底）

**二类买卖点（V2买/V2卖）：**
- 时间窗口限制（回调笔与离开笔相差30根K线内）
- 成交量确认（回调笔缩量）
- MACD确认（回调笔力度 < 离开笔力度）
- RSI确认（买入RSI<70，卖出RSI>30）

**三类买卖点（V3买/V3卖）：**
- 使用原始K线索引（k_index）而非合并序号
- 突破后价格站稳中枢上沿/跌破下沿
- 成交量配合（突破时放量）

## 二、Web UI改进

### ChanlunChart.vue 改进

**端点锚定优化：**
- 优先使用后端提供的bar_index锚点
- 回退到日期匹配（日线安全，分钟线不可靠）
- 确保买卖点/分型/笔/线段端点精确落在K线极值上

**背驰标记改进：**
- bi（笔背驰）= rect，橙色
- pz（盘整背驰）= circle，蓝色  
- qs（趋势背驰）= diamond，紫色

**买卖点标记改进：**
- 根据质量评级调整大小（S/A级更大）
- 标签显示「类型+评级」如「1buy·A」

**中枢区域改进：**
- 已完成中枢(zs.done=true)用稍深颜色
- 未完成中枢用淡色半透明

### ChanlunView.vue 改进

**市场状态判断：**
- 基于最新买卖点、中枢位置、当前价格综合判断
- 显示操作建议：买入/卖出/持有/观望

**关键价位参考：**
- 显示中枢上下沿、当前价格
- BOLL辅助分析

**买卖点准确度验证：**
- 显示按类型分组的命中率vs随机基准
- 让用户核对「哪类缠论买卖点真的准」

## 三、回测验证改进

### signal_accuracy.py 改进

**前瞻命中率计算：**
- BUY信号：未来N根收益 > 0 = 命中
- SELL信号：未来N根收益 < 0 = 命中（避开下跌）
- 随机基准：相同数量的随机入场点作为参照

**按类型分组验证：**
- compute_signal_accuracy_by_type()
- 对1buy/2buy/3buy/1sell等分别统计
- 排名展示各类型相对随机基准的超额命中率

**组合回测聚合：**
- aggregate_portfolio_accuracy()
- 多标的组合的加权命中率

## 五、使用建议

### 最佳实践
1. **日线级别**：使用默认配置（new笔规则，标准中枢）
2. **分钟线级别**：可适当降低中枢最少笔数
3. **短线交易**：重点关注1买/1卖（高准确率）
4. **中线持仓**：关注3买/3卖（趋势确认）
5. **风险控制**：结合信号准确度验证面板

### 回测验证流程
1. 使用「回测验证」按钮进入回测页面
2. 选择缠论策略（chanlun或changying_chanlun）
3. 查看「模型准确度验证」面板
4. 对比各类型信号的命中率vs随机基准
5. 使用「分段稳健性检查」验证过拟合风险

## 六、已知限制

1. **分钟线数据**：日期匹配可能不如日线精确，建议使用bar_index锚定
2. **极端行情**：涨跌停期间K线形态异常，缠论信号可能失效
3. **数据不足**：少于100根K线时，缠论结构可能不完整
4. **复权处理**：建议使用QFQ（前复权）数据，避免除权导致的形态断裂
