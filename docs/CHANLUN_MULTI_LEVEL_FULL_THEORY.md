# 缠论「真能提高买卖收益」方案：全量实测记录

> 目标：为 easy_tdx 缠论系统设计并实测一套**能真正提高用户买卖收益**的可执行方案，
> 覆盖此前**完全未测**的三个核心机制：
> 1. **区间套**（真跨周期：日线 + 真实 30min）
> 2. **多级别配合**（本级别买点进 + 次级别卖点出）
> 3. **不同买卖点类型的组合**
>
> 对照：**同级别配对** + **随机/局部低点**双基准；带成本；带样本外。
> **只保留实测有效的方案；无效方案如实记录。**

## 0. 结论摘要（全量 285 只，已跑完）

**没有一个方案通过三条判据。三个此前未测的机制全部无效。**

| 机制 | 结论 | 依据 |
|---|---|---|
| 真区间套（D1/D2） | ❌ **无效**。专项 24 组检验，未校正显著 3 组，**Bonferroni 校正后 0 组**；作为入场过滤器反而更差（D1 −13.35%、D2 −16.14%） | §3 / §5 |
| 多级别配合（B1-B4） | ❌ **无效**。最优的 B2 超额 −7.34%（t=−1.85），且 vs A1 −11.98% | §5 |
| 买点类型组合（E1/E2） | ❌ **无效**。1买 −23.47%、2买 −31.35%（最差） | §5 |

**同级别配对本身也不行**：A0（带守卫）超额 −19.58%（t=−5.14）、
A1（无守卫）+4.63% 但不显著（t=1.26）。

⇒ **本轮没能产出任何"实测有效"的方案**。这是诚实的阴性结果，
与 `docs/CHANLUN_CAN_IT_MAKE_MONEY.md` 的既有结论一致
（缠论的表观优势主要来自"局部低点低买高卖"的同义反复 + 熊市空仓）。

## 2. 判据（三条全过才算「真能帮用户赚钱」）

1. **超额 vs 买入持有**，|t| > 1.96 且为正
2. **超额 vs A1（同级别同口径）** 为正 ⇒ 不是"换个区间的好运"
3. **超额 vs RND（随机局部低点，同笔数）** 为正 **且** |t| > 1.96
   ⇒ 不是"低买高卖"的同义反复

### 为什么判据 2 用 A1 而不是 A0（这是实测发现的坑）

`ChanlunPairStrategy`（**现已废弃删除**，同口径改用
`ChanlunStrategy(stop_loss_pct=0, take_profit_pct=0)`）默认
`lookahead_guard=True`：信号要经 3 根确认期复核、
延后到 b+3 发出，实际 b+4 成交。而 `chanlun_ml` **没有**这套守卫。

⇒ 拿"带守卫的 A0"当对照 = 让对手**晚 3 根进场**，会**高估**多级别。

实测（25 只）：

```
A0 带守卫   +15.78%，平均 2.4 笔，笔均 +7.51%
A1 无守卫   +41.33%，平均 2.8 笔，笔均 +13.55%
差 25.56 个点（t=+5.39），25/25 只全部不同
```

但 **A1 也不是干净的**：PIT 扫描（20 只 × 5 个截断点 = 100 组）：

```
A0 guard=True : 100 组，不一致 4 组 (4.0%)
A1 guard=False: 100 组，不一致 7 组 (7.0%)
```

⇒ 所以**两条都报**。若某方案只在"拿 A0 当对照"时成立、换成 A1 就不成立，
那它多半是口径差，不是真优势。

```
信号总数 3262   区间套确认率 72.4%
```

### 结论：Bonferroni 校正后**没有任何一组**显著

```
多重比较：共 24 组检验  ⇒ Bonferroni 校正后阈值 |z|>3.08
          未校正（|z|>1.96）在原假设下期望假阳性 1.20 组

未校正显著（|z|>1.96）: 3/24 组
Bonferroni 校正后显著（|z|>3.08）: 0/24 组
⇒ 没有任何一组在多重比较校正后显著 ⇒ 区间套作为过滤器没有可证的增量
```

那 3 组"未校正显著"的分别是（正值 = 确认组更好）：

| 分组 | 差 | z | 校正后 |
|---|---|---|---|
| 1buy @5 根 | +0.62% | z=+1.98 | ⚠️ 不显著 |
| 2buy @10 根 | +3.57% | z=+2.21 | ⚠️ 不显著 |
| 1buy @20 根 | +1.62% | z=+2.02 | ⚠️ 不显著 |

读法：
- **3buy**（用户最关心的"本级别 3 买"）确认后**几乎完全没差**：
  @5 **+0.02% (z=0.03)**、@10 +0.20% (z=0.22)、@20 **−2.04% (z=−1.28)**
- 卖点（1sell/3sell）确认基本无效（3sell 是主要出场方式）
- 那 3 组 z 都在 1.96~2.21，**恰好落在多重比较最易产生假阳性的区间**：
  24 组 × 5% = 期望 1.2 组假阳性，实测 3 组 —— 校正后归零

⇒ **区间套作为过滤器没有可证的增量价值**。这与缠论原文
"区间套确认的买卖点可靠度显著更高"**不符**。

⚠️ **方法论提醒**：如果只报"3 组显著"而不做多重比较校正，会得出相反的
（错误的）结论。本轮是跑完看到 3 组 z≈2 才意识到必须校正，
已在脚本里内置 Bonferroni（阈值随检验组数自动收紧）。

### ⚠️ 确认率口径修正（不要再引用 26.1%）

早期 8 只冒烟报确认率 **26.1%**，现在全量 285 只报 **72.4%**。不是模型变了，
是**口径修正**：早期拿**全长日线**（1500 根，2020 起）的信号去配**只有 2024-09 起**
的 30min 数据 —— 其中大量信号的笔结束时间**早于** 30min 起点，根本没有低级别
结构可查，必然判"未确认"。

实测（sh600000）：

```
旧（全日线 1500 根）：40 信号 / 确认 12 = 30.0%，21 个早于 30min 起点
新（截断到 494 根） ：13 信号 / 确认 9  = 69.2%，0 个越界
```

## 6. 过程中修掉 / 证伪的自身错误（纪律 §3：实测证伪要回头改文档）

### 6.1 证伪：「坏对齐 ⇒ 次级别卖点永远不触发、全退化 max_hold」

我原在 `chanlun_ml.py` 注释里这么写。30 只实测**推翻**：

```
好版本出场分布 {'1sell': 104, 'max_hold': 10}
坏版本出场分布 {'1sell': 104, 'max_hold': 10}   ← 完全相同
逐笔比较: 相同 10, 不同 104；不同的笔 exit_bar 延迟 min=1 max=1 mean=1.00
平均收益 好=+23.71%  坏=+21.34%   配对差 −2.367% (t=−2.15)
```

真实后果是**晚一天卖出**，不是"功能失效"。注释已改，并加了
`verify_ml_sub_exit_fires.py` 的**牙齿 4**（注入坏对齐必须产生可观测差异）——
因为前三条断言（占比/归因/持仓更短）**抓不住"延迟一根"**，实测会全部通过。

### 6.2 修掉：恒真的假 PIT 检测

我写过一版 PIT 检查，同时截断了日线和次级别数据，但**信号仍用全量注入**
（`set_precomputed` 传全量序列）⇒ 30/30 全"一致"，因为信号根本没截断。
**不管策略有没有未来函数它都会报 ✅**。

⇒ 新增 `scripts/verify_ml_pit_teeth.py`，三条判据：
1. 截断一致
2. **非空**（截断内必须有实质配对，否则 `[] == []` 恒真）
3. **注入可检出**：人为把次级别信号提前 5 天，必须报 ❌

实测 10 只：6/6 一致、6/6 注入被检出、4 只因截断内 0 笔被**排除而非计入通过**。

### 6.3 修掉：RND 基准不公平

原实现用 B2 的笔数给**所有**方案生成随机基准。不同方案笔数差很多
⇒ 改成**逐方案**按各自笔数生成。

### 6.4 修掉：`hash(code)` 做种子

Python 的 `str.__hash__` 带 salt，**跨进程不可复现** ⇒ 改用 md5
（`_stable_seed`）。

## 8. 结论：可交付的方案 = 无

按"只保留实测有效的方案"的纪律，**本轮没有产出任何可推荐方案**：

| 候选 | 处置 |
|---|---|
| 区间套过滤（D1/D2） | ❌ 不采用。24 组检验 Bonferroni 后 0 组显著；加入后方案更差 |
| 多级别配合（B1-B4） | ❌ 不采用。全量超额 −7%~−20% |
| 买点组合（E1/E2） | ❌ 不采用。1买 −23%、2买 −31% |
| 同级别配对（A0/A1） | ❌ 不采用。−19.58% / +4.63%(不显著) |

**已落地处置**：`chanlun_ml` **不登记**进策略预设网格
（`src/easy_tdx/backtest/strategies/presets.py`），避免用户在 UI 一键跑到
已被证伪的参数上；并由 `tests/unit/test_presets_grid.py` 守住这条。

### 给用户的一句话
**在当前 2 年样本、285 只 A 股、含真实成本与次级别（30/60min）数据的条件下，
缠论的区间套与多级别配合都没有测出可持续的超额收益。**
此前看到的"效果"经分解主要是：① 局部低点买入的同义反复；② 熊市空仓的仓位效应
（样本外符号翻转就是这条的直接证据）。
