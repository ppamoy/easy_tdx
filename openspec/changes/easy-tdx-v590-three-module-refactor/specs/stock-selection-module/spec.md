# Spec: stock-selection-module（选股：长盈基本面 + 缠论择时）

## 背景
新建/改造单页选股流程：用户选择时间（point-in-time）→ 先用长盈理论选基本面标的池 → 再用缠论做择时交易，输出可解释的两步结果。

## ADDED Requirements

### Requirement: 时间选择驱动 point-in-time 分析
选股页提供历史日期选择（可含区间），第一步只使用「截至目标日已披露」的财报，缠论分析只使用「截至目标日」的前复权 K 线，杜绝未来函数。本要求为强制约束（MUST）。

#### Scenario: 选择历史时间
- **WHEN** 用户选择一个历史日期 T 并触发选股
- **THEN** 长盈基本面评分只基于 T 之前已披露财报，缠论 K 线窗口结束于 T，页面明确标注「数据截至 T」

### Requirement: 第一步长盈基本面选股池
后端按长盈理论（树粮菜三维）对标的池评分，输出分类、质量分、打分明细，并按分数排序。标的池支持热门池（默认）与全市场（后台任务 + 进度）。本要求为强制约束（MUST）。

#### Scenario: 返回树粮菜标的池
- **WHEN** 用户提交选股请求
- **THEN** 返回列表每个标的包含 symbol、category（tree/grain/vegetable）、score、各维度明细，按 score 降序

#### Scenario: 全市场扫描进度
- **WHEN** 用户选择全市场池
- **THEN** 返回任务 ID，前端轮询进度，不因同步长连接超时而失败

### Requirement: 第二步缠论择时
对基本面池内标的（单只或全部）做缠论分析，输出三类买卖点、背驰、中枢与择时结论（买入/观望/卖出 + 建议），并可在图表上核对。本要求为强制约束（MUST）。

#### Scenario: 单标的择时详情
- **WHEN** 用户在池中选中一只标的
- **THEN** 右侧展示该标的截至目标日的 ChanlunChart（笔/线段/中枢/买卖点/背驰）+ 择时结论卡片

#### Scenario: 批量择时汇总
- **WHEN** 用户选择「全部择时」
- **THEN** 列表每行追加最新信号类型、信号日期、方向、置信度与操作建议，可再点入详情

### Requirement: 两步结果可解释
页面分别展示「基本面为什么入选」与「缠论为什么此时交易」，不把两阶段信号混成单一黑盒分数。本要求为强制约束（MUST）。

#### Scenario: 解释拆开展示
- **WHEN** 查看某标的详情
- **THEN** 能看到长盈分类与评分明细（第一阶段）和缠论买卖点/背驰依据（第二阶段）两个独立区块
