# 缠论学习页面需求梳理（easy-tdx-chanlun-learning）

## Why

学习页面已实现单点盘感训练，但缺少系统教学闭环与「按日期批量实证验证买卖点」的硬核验证能力，无法支撑「通过图表展示长盈选股+缠论择时交易的准确性」的项目目的。本 change 将学习页面升级为教学+训练+进度+实证验证四位一体系统。

## What Changes

- 难度分级出题、随机标的选择（训练增强）
- 排行榜周期/难度筛选与分组统计
- 错题正确解读与错题集
- 学习进度聚合与成绩趋势曲线
- 按日期批量实证验证买卖点（预置大市值标的池、后台预跑、逐一呈现、逐根揭示、同级别中枢）
- 缠论概念图文教学与逐步可视化构建


## 动机（Motivation）

`/train` 页（TrainView.vue，1300 行）已实现盘感训练的三大模式——逐步揭示训练、买卖点复盘讲解、训练排行榜——并接入 V102 决策支持展示与成绩持久化（V90）。但作为「学习页面」，当前实现集中在**单点盘感训练**，缺少系统的教学闭环，且**缺少「按日期批量实证验证买卖点」的硬核验证能力**。

本 change 将学习页面升级为「**缠论教学 + 盘感训练 + 进度追踪 + 买卖点实证验证**」四位一体的系统，需求按七个能力域梳理。

## 现状盘点（Audit）

| 能力 | 现状 | 差距 |
|---|---|---|
| 逐步揭示训练 | ✅ 候选点提问、答案揭示、V102 建议、事后20日验证 | 无难度分级、无随机标的选择 |
| 复盘讲解 | ✅ 逐笔买卖点表格 + 事后表现 + V102 质量卡 | 无「为什么成立」的结构化讲解卡、无图例标注 |
| 排行榜 | ✅ 得分/命中率/标的信息 | 无周期/难度筛选、无历史成绩曲线 |
| 理论教学 | ❌ 无 | 完全缺失 |
| 教学可视化 | ⚠️ 仅 reveal-index 截断 | 无中枢/笔逐步构建动画 |
| 进度追踪 | ❌ 无（仅一次性提交） | 完全缺失 |
| 买卖点实证验证 | ⚠️ screening 有日期扫描但面向长赢模型；无预置标的池 | 缺「后台预跑大市值标的 + 买卖点后逐根 K 线实证」 |

## 七能力域概述（Spec Overview）

1. **theory-lessons** — 缠论概念教学：分型/笔/线段/中枢/三类买卖点/背驰的图文讲解页
2. **visual-teaching** — 逐步构建可视化：K 线推进中高亮显示笔/中枢如何成形
3. **difficulty-tiering** — 难度分级 + 随机标的：按置信度区间/信号类型出题
4. **mistake-feedback** — 错误归因：判断错后给出「正确解读」讲解
5. **progress-tracking** — 学习进度：历史成绩、命中率曲线、掌握度统计
6. **leaderboard-enhance** — 排行榜增强：周期/难度筛选 + 分组
7. **signal-backtest-verification** — 买卖点实证复盘：后台预跑 20 只大市值/大成交量标的 → 逐一呈现（一次一只）→ 展示买卖点 + 买卖点后逐根 K 线揭示 + 同级别中枢

## 影响评估（Impact）

- **前端**：TrainView.vue 重构为学习页容器（路由 /learn），新增 TheoryLessons / VisualTeaching / ProgressDashboard / SignalVerify 组件，ChanlunChart 扩展高亮/标注/同级别中枢能力
- **后端**：train/session 扩展难度与随机参数；新增 /learn/lessons、/learn/progress、/verify/signals 端点（预跑池 + 单标的详情）；train_store 扩展掌握度聚合
- **数据**：训练成绩表扩展 difficulty/category 维度；新增学习进度表；买卖点验证复用离线 .day 扫描
- **测试**：前端 vitest（组件 + 视图冒烟）、后端 pytest（新端点契约 + 纯函数）

## 成功标准（Success Criteria）

1. `/learn` 页七能力域均可访问且有真实内容
2. 逐步揭示训练支持难度分级与随机标的，且出题可复现（seed）
3. 答错后必有「正确解读」讲解（mistake feedback），覆盖 100% 错题
4. 学习进度页展示历史成绩曲线与分周期命中率
5. 排行榜可按周期/难度筛选
6. 实证验证页：后台预跑 20 只大市值标的，**一次只展示一只**，展示买卖点标注，支持**买卖点后逐根 K 线揭示**，K 线图显示一个同级别中枢（无需用户选日期）
7. 全部门禁通过：ruff/mypy/pytest/vue-tsc/vite build/vitest
